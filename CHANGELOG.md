# Changelog

Все значимые изменения в CLEARGATE документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Документация и ADR (7 архитектурных решений)
- Task files для Claude Code (10 задач MVP)
- Pre-commit hooks, pyproject.toml, docker-compose

### Fixed
- ORG-анонимизация стала precision-first: широкие GLiNER `organization` /
  `location` больше не применяются автоматически, родовые фразы вроде
  `Адвокатское бюро` и `Бюро` фильтруются, а профессиональные фирмы с
  отличительным названием вроде `Адвокатское бюро ЕПАМ` распознаются.
- Frontend production bundle no longer falls back to `localhost` API URLs when
  `NEXT_PUBLIC_API_URL` is not set; nginx deployments use same-origin `/api`
  and `/ws`, and `/api/auth/me` has a timeout so the UI cannot hang forever on
  session check.
- Backend Docker build больше не зависит от `python -m spacy download` и
  `raw.githubusercontent.com`; `ru_core_news_lg` ставится из direct wheel URL.
- Убрана no-download fallback-ветка Presidio: backend теперь не стартует без
  обязательной Russian spaCy model, чтобы не снижать качество анонимизации.
- GPU pilot inference stack обновлен до pinned Qwen3/BGE-M3-compatible images:
  `vllm/vllm-openai:v0.9.2` и
  `ghcr.io/huggingface/text-embeddings-inference:89-1.9`.
- GPU compose больше не поднимает `ollama` по наследству из base profile;
  backend зависит только от `vllm` и `bge-embedder`.
- Installer валидирует `HF_ENDPOINT` как абсолютный URL и печатает container
  logs/health details при долгом unhealthy-состоянии.
- TLS symlinks для nginx в режимах `selfsigned` и `corp_ca` теперь создаются
  относительными, чтобы не ломаться внутри mount `/etc/cleargate-certs`.

## [1.0.4] - 2026-05-06

### Fixed
- Compare view больше не собирает переносы из визуальных строк docx-preview: `из` / `сюда` теперь определяются по целым numbered-разделам договора с их подпунктами.
- Мелкие word-diff фрагменты внутри найденного переноса отфильтровываются, чтобы не смешивать перенос блока с россыпью частичных вставок и удалений.

## [1.0.3] - 2026-05-06

### Changed
- Compare view теперь создает парную подсветку для найденных переносов: `из` в старой позиции и `сюда` в новой позиции, даже если базовый word-diff счел текст неизмененным.

## [1.0.2] - 2026-05-06

### Changed
- Эвристика заголовков документов теперь учитывает акты сверки и даты словами, например `от 31 декабря 2024 г.`.
- Панель неразрешенных плейсхолдеров стала управляемой React-формой и показывает ошибку применения прямо в интерфейсе.
- Compare view дополнительно подсвечивает место назначения для крупных перенесенных абзацев, даже если word-diff сопоставил сам текст как неизмененный.

### Fixed
- `АКТ ВЗАИМНОЙ СВЕРКИ РАСЧЁТОВ` больше не анонимизируется как организация.
- Ручное применение плейсхолдеров вроде `[ОТСУТ_1]` больше не падает при сохранении workflow-состояния.

## [1.0.1] - 2026-05-06

### Added
- Панель предложений глубокой проверки: добавления и удаления теперь видны отдельно, их можно включать/отключать по одному без повторного прогона.
- В сравнении с оригиналом крупные переставленные фрагменты подсвечиваются как перемещение, а не только как разрозненное удаление и вставка.

### Changed
- При дозагрузке файлов в сессию название документа больше не превращается в `+ 1 файл`; существующее имя остается стабильным, а новый пакет получает аккуратный суффикс `_1` только при первичной мультизагрузке.
- Ручное разрешение новых плейсхолдеров нормализует варианты вроде `СРОК 1`, `СРОК-01` и `[СРОК_1]` к одному ключу.

### Fixed
- `Роспатент`, `ФНС`, `Росреестр` и полные названия ведомств не анонимизируются как обычные организации в Deep Scan/post-process.
- Кнопка применения ручных значений больше не переводит основной workflow в состояние `Деанонимизируем` и блокирует только саму операцию применения.

## [1.0.0] - 2026-05-06

### Added
- Загрузка нескольких DOCX/PDF/TXT в одну сессию: файлы объединяются по порядку загрузки, анонимизируются как единый пакет и скачиваются одним DOCX.
- Дозагрузка документов в существующую сессию с явным подтверждением сброса старой анонимизации.
- Reversible QA Deep Scan: глубокая проверка теперь может не только предлагать новые сущности, но и отключать сомнительные false positives отдельным обратимым слоем.
- Golden fixtures для ЕГРЮЛ и PDF-derived аренды, включая суммы, сроки, реквизиты, адреса и типовые ложные срабатывания.

### Changed
- Deep Scan переведен в режим проверочного слоя: его можно включить, отключить и повторно включить без потери базовой разметки.
- В режиме сравнения скрываются плашки деанонимизации и нижняя статистика сущностей, чтобы diff не смешивался с восстановлением данных.
- Кнопки рабочей области приведены к единому шрифту и плотности.

### Fixed
- PDF-derived суммы вида `Двести тысяч (200 000) рублей` распознаются как `СУММА`.
- Относительные сроки вроде `10 дней`, `11 месяцев`, `30 дней` больше не добавляются глубокой проверкой как даты.
- Заголовок `ВЫПИСКА` и похожие документные заголовки не анонимизируются как организации.
- Post-process глубокой проверки умеет предлагать удаления ложных сущностей, а не только добавлять новые.

## [0.9.2] — 2026-05-06

### Added
- Переключаемый слой глубокой проверки: предложения можно включать и отключать без повторного прогона.
- Сохранение workflow ответа LLM: импортированный ответ, деанонимизированный DOCX и ручные разрешения восстанавливаются при повторном входе в сессию.
- Регрессии для PDF-derived договоров: заголовки, суммы, валюты, английские компании, адреса и реквизиты.

### Changed
- Глубокая проверка стала QA-слоем поверх базовой разметки, а не необратимой заменой результата.
- В режиме сравнения скрываются плашки деанонимизации, чтобы не смешивать diff и восстановленные значения.
- Выравнен шрифт и размер текста на кнопках рабочей области.

### Fixed
- PDF-аренда: `ООО «Промышленная недвижимость СПб»`, суммы в рублях и английские компании распознаются стабильнее.
- Убраны false positives для `кв.м.`, НДС/пени в процентах, `Арендодателя`, `РЕКВИЗИТЫ`, валютных кодов вроде `CNY`.
- Адрес больше не захватывает соседние банковские реквизиты (`Банк: ПАО ВТБ`).
- Заголовки документов (`ЗАЁМ`, `ДИСТРИБУЦИЯ` и похожие) не анонимизируются как организация или место.

## [0.1.1-alpha] — 2026-04-10

Вторая итерация Alpha — улучшение качества NER, новый дизайн в стиле АБ ЕПАМ.

### Added
- **Stopwords system** — фильтрация ~80 юридических терминов («Исполнитель», «Заказчик»,
  «Генеральный директор», «БИК», «Арбитражный суд», «Приложение №N», «Устав» и др.)
  с fuzzy-stem matching для падежных форм
- **ContractNumberRecognizer** — распознавание номеров договоров
  (ТЛ-2026/047, 12-А/2026, 2026-001)
- **Adjacent PER merging** — соседние PER-сущности в пределах 3 символов
  сливаются в одну («Петрова» + «Алексея Николаевича»)
- **Regression test suite** — 9 тестов для конкретных багов из Alpha v0.1.0
- **EPAM design system** — бордовый акцент `#8B1A2B`, PT Serif для заголовков,
  Inter для текста, тёплые серые тона
- **Entity highlighting** — подсветка сущностей цветными `<mark>` тегами
  в левой панели после анонимизации
- **DocumentUpload** — drag-and-drop загрузка DOCX/PDF/TXT в split-screen
- **EntityNavigator** — правая боковая панель с группировкой сущностей по типам
- **HTTP LLM endpoint** (`POST /api/sessions/{id}/llm`) — синхронная альтернатива
  WebSocket стримингу для надёжности

### Changed
- INN base score повышен с 0.3 до 0.5 (исправляет конфликт с Passport recognizer)
- Passport regex теперь требует пробел между серией и номером
- Header переработан в стиле ЕПАМ (бренд-метка V, status dot, локализованные тоглы)
- LLMPanel переключён с WebSocket на HTTP POST для надёжности
- Layout перестроен: трёхколоночная схема (SplitScreen + LLM Panel + Entity Navigator)

### Fixed
- ИНН организации (10 цифр) больше не определяется как паспорт
- ОГРН корректно распознаётся (overlap resolution отдаёт приоритет regex-validated сущностям)
- «Генерального директора» в любом падеже не попадает в сущности
- «Исполнитель», «Заказчик», «Заявки», «БИК», «МО», «Устав», «Арбитражный суд» —
  отфильтровываются как false positives
- ФИО («Петрова Алексея Николаевича») сливается в одну PER-сущность
- LLM-запрос возвращает понятную ошибку вместо «Internal Error»

## [0.1.0-alpha] — 2026-04-09

Первый запуск Alpha-конфигурации на ASUS ROG G14 (RTX 4060).

### Added
- **Backend**: FastAPI 0.135 + Pydantic v2, Python 3.12
- **Task 01**: Health endpoint, базовый skeleton с тестами (8 тестов, 100% coverage)
- **Task 02**: 9 Presidio regex-распознавателей российских PII
  (ИНН, ОГРН, СНИЛС, паспорт, банк. счёт, телефон, email, дата, номер дела)
  с валидацией контрольных сумм (30 тестов)
- **Task 03**: Трёхслойный NER pipeline (regex + spaCy ru_core_news_sm + GLiNER + Ollama Qwen)
  с post-processing (slow span merging, overlap resolution)
- **Task 04**: EntityRegistry с консистентным маппингом placeholder'ов,
  pymorphy3 нормализацией, Levenshtein fuzzy matching, AES-256-GCM шифрованием
- **Task 06**: REST API — sessions, documents/upload, anonymize, deanonymize, entities
- **Task 07**: ClaudeAdapter — нативный Anthropic SDK, extended thinking,
  streaming, cost estimation
- **Task 08**: WebSocket `/ws/stream` для стриминга ответов LLM
- **Frontend**: Tauri 2.10 + Next.js 15 + React 19 + TypeScript strict
- **Tasks 05/09/10**: SplitScreen, LLMPanel, theme (light/dark), i18n (RU/EN)
- **START-CLEARGATE-Alpha.bat** — launcher для быстрого запуска

### Security
- AES-256-GCM шифрование mapping table в памяти
- HKDF-SHA256 деривация сессионных ключей из мастер-ключа
- Whitelist логирование (никаких PII в логах)
- 4 неприкосновенных принципа из `SECURITY_MODEL.md`
