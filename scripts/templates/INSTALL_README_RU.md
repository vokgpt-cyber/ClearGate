# Cleargate - Установка пилота (оффлайн-пакет)

Этот пакет устанавливает Cleargate на пилотный сервер **без необходимости интернет-доступа** (кроме установки Docker).

## Требования к серверу

- **Windows Server 2019 / 2022** (64-разрядный)
- **32 ГБ RAM** минимум (16 ГБ работает, но модель будет медленной)
- **4+ ядер CPU**
- **25 ГБ свободного места** на системном диске
- Права **Администратора**
- **Docker Desktop для Windows Server** установлен и запущен
  (https://docs.docker.com/desktop/install/windows-install/)

## Установка (5 шагов)

1. Скопируйте всю эту папку на целевой сервер (например, `C:\Cleargate\`).
2. Установите Docker Desktop, если его ещё нет. Запустите и дождитесь, когда иконка кита перестанет анимироваться.
3. Правый клик на `offline-install.bat` -> **Запустить от имени администратора**.
4. Подождите ~5 минут, пока загрузятся образы и поднимутся контейнеры.
5. Откройте `http://<ip-сервера>` в браузере (или `http://localhost` прямо на сервере).

### Первый вход

Автоматически создаются два пользователя:
- **test1** / пароль: `cleargate-pilot`
- **test2** / пароль: `cleargate-pilot`

**ВАЖНО: смените эти пароли перед передачей доступа реальным пользователям.**

```
users.bat reset-password test1
users.bat reset-password test2
```

## Ежедневные операции

| Задача                    | Команда           |
|---------------------------|-------------------|
| Запустить сервис          | `start.bat`       |
| Остановить сервис         | `stop.bat`        |
| Проверить состояние       | `status.bat`      |
| Смотреть логи             | `logs.bat`        |
| Управление пользователями | `users.bat ...`   |
| Переустановить            | `offline-install.bat` (безопасно повторять) |

## Устранение проблем

**Preflight ругается "Port X is held by..."**: другое приложение занимает порт (80/3000/8000/11434). Остановите его и повторите.

**Docker не отвечает**: запустите Docker Desktop, дождитесь стабилизации иконки, повторите.

**"Failed to fetch" в браузере**: запустите `offline-install.bat` заново - он пересоберёт фронтенд с правильным IP.

**Модель очень медленная (> 5 мин на запрос)**: не хватает RAM. Проверьте: `Get-CimInstance Win32_ComputerSystem | Select TotalPhysicalMemory`.

## Поддержка

Свяжитесь с командой Cleargate, приложив вывод `status.bat` и последние 100 строк `logs.bat`.
